# Repository Mirrors & Remotes

The `example-dns` monorepo is maintained and synchronized across multiple platforms for redundancy and public accessibility:

| Platform | URL | Role |
| --- | --- | --- |
| **GitHub** | [https://github.com/example-dns/example-dns](https://github.com/example-dns/example-dns) | Public repository and issue tracking |
| **Codeberg** | [https://codeberg.org/example-dns/example-dns](https://codeberg.org/example-dns/example-dns) | Public mirror and open-source platform hosting |

## Git Remote Setup

To configure both remotes in your local development clone:

```bash
# Add GitHub remote
git remote add github https://github.com/example-dns/example-dns.git

# Add Codeberg remote
git remote add codeberg https://codeberg.org/example-dns/example-dns.git
```
